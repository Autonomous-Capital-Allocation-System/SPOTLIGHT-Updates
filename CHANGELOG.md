# Changelog

## 1.0.0 (2026-10-18)

First full release. Code-signed installers (Windows Authenticode; macOS Developer ID + notarized), a much stronger Impact engine (Amount 0-200%, new Punch / Drive / Density moves, Solo Contrast), license activation with a free trial, updates that download and install from inside the plug-in, and a new 1.0 user guide.

## 0.1.0-alpha.1 — first testable build

- Linked multi-instance spotlighting: put SPOTLIGHT on several tracks, light one,
  the rest recede (dynamic carve, dip, darken, narrow, depth). Zero routing.
- Solo mode for a single track (forward moves only).
- Three trigger sources per instance: Automation lane, tempo-synced 16-step Grid, Audio threshold.
- Rise / Hold / Fall timing with tempo-synced fall.
- Priority arbitration, and a per-track "Recedes" switch.
- One Amount dial, three character profiles (Punch / Focus / Bloom), Advanced per-move controls.
- Presets, manual update check, VST3 (Windows) and VST3 + AU universal (macOS).
