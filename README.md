# SPOTLIGHT updates

Public version manifest and changelog for **SPOTLIGHT**, the mix-focus
plug-in by ACAS Tools.

The SPOTLIGHT plug-in reads `update-manifest.json` from this repository's `main`
branch when — and only when — a user clicks **Check for updates** in the
plug-in. The request carries no account, project, preset, or device
information, and the plug-in never downloads or executes files itself; it
only opens the download page in the user's browser.
